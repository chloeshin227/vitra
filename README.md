## 1. 프로젝트 소개

VITRA는 의료정보를 환자와 보호자가 이해하기 쉬운 시각적 정보로 변환하여 제공하는 웹 애플리케이션 프로토타입이다.

질환 정보, 신체 부위, 치료 방법, 수술 및 치료 과정, 의약품 정보를 하나의 웹 애플리케이션에서 탐색할 수 있도록 구성하였다.

의료진의 설명을 보조하고 환자와 보호자의 의료정보 이해를 돕는 것을 목적으로 한다. 독자적인 진단이나 처방을 수행하는 프로그램은 아니다.

## 2. 주요 기능

1. 질환 정보 분석
   - 입력된 질환 관련 키워드를 분석하여 등록된 질환 정보를 표시한다.

2. 신체 부위 시각화
   - 질환과 관련된 신체 부위를 인체 이미지와 연결하여 시각적으로 확인할 수 있도록 한다.

3. 질환 검색
   - 질환명을 입력하여 관련 의학 정보를 탐색할 수 있도록 한다.

4. 치료 방법 비교
   - 일부 질환의 치료 방법별 특징을 비교할 수 있도록 한다.

5. 수술 및 치료 과정 시각화
   - 수술 및 치료의 진행 단계를 순서대로 확인할 수 있도록 한다.

6. 의약품 정보 검색
   - 공공데이터 기반 API를 활용하여 의약품 관련 정보를 검색할 수 있도록 한다.

## 3. 사용 방법

1. VITRA 웹 애플리케이션에 접속한다.
2. 메인 화면에서 이용하고자 하는 기능을 선택한다.
3. 질환 검색 기능에서는 질환명 또는 관련 키워드를 입력한다.
4. 분석 결과를 확인하고 제공되는 관련 기능을 탐색한다.
5. 의약품 검색 기능에서는 검색어를 입력하여 관련 정보를 확인한다.

## 4. 실행 방법

- Python 환경에서 프로젝트에 필요한 라이브러리를 설치한다.
- Streamlit을 이용하여 애플리케이션을 실행한다.
- API를 사용하는 기능은 해당 API의 인증 정보와 환경 설정이 필요하다.
